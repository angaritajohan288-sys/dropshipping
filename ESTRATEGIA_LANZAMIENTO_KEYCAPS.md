# Estrategia de lanzamiento: Keycaps PBT de gato

## Propósito de la prueba

El objetivo de la primera semana no es prometer ventas ni escalar anuncios. Es validar si personas en Colombia interesadas en teclados mecánicos hacen clic, entienden la compatibilidad y muestran intención de compra ante una propuesta clara. La única promesa de entrega será la que devuelva el proveedor para la variante final.

> **Producto:** set de 124 keycaps PBT de gato, perfil MOA, para teclados mecánicos compatibles con switches MX.  
> **No compatible:** teclados de portátil, de membrana ni layouts que no tengan las teclas requeridas.

## Cliente prioritario

La comunicación se enfoca en personas en Colombia que ya tienen un teclado mecánico y valoran personalizar su escritorio. El mensaje no debe dirigirse a quien busca un teclado barato ni a usuarios de portátil: el producto es una modificación estética para un hobby de nicho.

| Segmento | Problema / deseo | Mensaje central |
|---|---|---|
| Propietarios de teclado mecánico | Teclado funcional pero visualmente genérico. | “Cambia tu setup sin comprar otro teclado.” |
| Fans de setups claros, kawaii o minimalistas | Buscan coherencia visual para escritorio o streaming. | “Un set completo para un teclado que sí se vea tuyo.” |
| Compradores de regalo | Quieren un artículo visual para alguien aficionado a teclados. | “Regalo para quien ya cuida cada detalle de su setup.” |

## Página de producto imprescindible

La página debe mostrar la imagen de la variante exacta y, antes del botón de compra, un bloque simple:

> **Antes de pedir:** compatible con la mayoría de teclados mecánicos que usan switches MX y layouts estándar. No sirve para teclado de portátil ni de membrana. Verifica las medidas y la barra espaciadora de tu teclado antes de comprar.

El contenido debe incluir: foto con todas las teclas, material PBT, perfil MOA, número de piezas, formatos compatibles, instrucciones básicas de instalación, ventana real de entrega, política de devoluciones y soporte. No afirmar que mejora el rendimiento de juego ni que sirve para todos los teclados.

## Contenido orgánico primero

Antes de pagar anuncios, se deben preparar tres piezas verticales propias con el producto físico o con material autorizado del proveedor. No se publicarán videos que hagan creer que el equipo del usuario fue transformado si no ocurrió.

| Pieza | Guion de 10–20 segundos | Llamado a la acción |
|---|---|---|
| Transformación | Teclado mecánico compatible antes → detalle de instalación → resultado final. | “Revisa si tu teclado usa switches MX.” |
| Compatibilidad | Mostrar en pantalla “¿Portátil o membrana? No. ¿Teclado mecánico MX? Sí.” | “Guarda esta guía antes de elegir keycaps.” |
| Detalle visual | Tomas cercanas de textura PBT, iconos de gato y sonido de pulsación real. | “Personaliza tu setup sin cambiar el teclado.” |

Publicar una pieza por día en TikTok, Instagram Reels y YouTube Shorts, adaptando el texto y respondiendo preguntas de compatibilidad. Las respuestas y mensajes sirven como señal de interés real antes de invertir.

## Publicidad de prueba: solo después de checkout y muestra

La publicidad pagada no se activa hasta que la ficha, el checkout y la entrega estén verificados. Cuando estén listos, se puede hacer una prueba pequeña y medible, no una apuesta abierta.

| Componente | Configuración inicial |
|---|---|
| Canal | Meta Ads con Reels/Stories; reutilizar el video orgánico que retenga mejor atención. |
| Objetivo | Visitas a la página del producto durante la primera validación; cambiar a ventas solo si el píxel/checkout están comprobados. |
| Público de prueba | Colombia, mayores de edad, intereses relacionados con teclados mecánicos, personalización de escritorio y gaming; contrastar con un grupo amplio. |
| Creativos | Dos versiones: transformación del teclado y guía de compatibilidad. |
| Regla de control | Pausar cualquier anuncio que atraiga clics pero genere dudas repetidas sobre compatibilidad o entrega. |
| Medición | Visitas de calidad, clic en “agregar al carrito”, inicio de checkout, preguntas y compras. |

**Presupuesto recomendado de prueba:** COP 90.000 en total, limitado a COP 30.000 diarios durante tres días. Es un límite de aprendizaje, no una garantía de ventas. El gasto se detiene antes si hay dudas reiteradas por compatibilidad/entrega, errores de checkout o tráfico sin señales de intención. No se incrementa el presupuesto sin revisar resultados de los tres días.

## Anuncios listos para adaptar

### Anuncio A — Transformación de setup

**Copy principal:**

Tu teclado mecánico no tiene que verse igual que todos. Este set de 124 keycaps PBT cambia tu setup con un diseño de gato, textura resistente y piezas para layouts estándar compatibles. Antes de pedir, revisa que tu teclado use switches MX.

**Titular:** Personaliza tu teclado mecánico.

**Descripción:** Keycaps PBT de 124 piezas. Entrega internacional estimada visible antes de pagar.

**CTA:** Ver compatibilidad.

**Guion Reel/Story:** “¿Tu teclado mecánico sigue viéndose básico? Mira el cambio con un set completo de keycaps PBT. Si usas switches MX, revisa la compatibilidad antes de pedir.”

### Anuncio B — Filtro de compatibilidad

**Copy principal:**

Esto no es otro teclado: es una forma de hacerlo tuyo. Keycaps PBT de gato para teclados mecánicos compatibles con MX. No sirve para portátil ni membrana; te explicamos cómo verificar el tuyo antes de comprar.

**Titular:** ¿Tu teclado es compatible?

**Descripción:** Guía de layouts y envío informado.

**CTA:** Revisar mi teclado.

**Guion Reel/Story:** Pantalla 1: “¿Portátil o membrana? No.” Pantalla 2: “¿Teclado mecánico con MX? Puede que sí.” Pantalla 3: “Revisa el layout y personaliza tu setup.”

### Anuncio C — Regalo de nicho

**Copy principal:**

Para quien ya cuida cada detalle de su setup: un set completo de keycaps PBT con diseño de gato. Un regalo pensado para teclados mecánicos compatibles, no para cualquier teclado.

**Titular:** Un detalle para su setup.

**Descripción:** Diseño de gato, 124 piezas y compatibilidad explicada.

**CTA:** Ver el set.

**Guion Reel/Story:** Detalles cercanos de las teclas, empaque y resultado final en un teclado compatible, sin afirmar resultados no demostrados.
