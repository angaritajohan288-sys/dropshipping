# Plantilla de control de pedidos — Organizador de cables

**Estado:** plantilla interna vacía preparada. No contiene datos de clientes, no se conecta a Shopify ni DSers y no activa pagos, mensajes, publicaciones o campañas.

## Archivo generado

La plantilla se creó como `PLANTILLA_CONTROL_PEDIDOS_ORGANIZADOR.xlsx` con tres hojas: **Control de pedidos**, **Listas** e **Instrucciones**. La hoja principal contiene 18 campos operativos, filtros, columnas congeladas y listas desplegables para los estados de pago, operación, envío y soporte.

| Hoja | Uso |
|---|---|
| Control de pedidos | Registrar únicamente referencias de orden, variante, verificaciones, estado y siguiente acción interna. |
| Listas | Mantener valores estandarizados para evitar estados escritos de forma inconsistente. |
| Instrucciones | Recordar reglas de verificación, rastreo y minimización de datos. |

## Regla de uso seguro

La plantilla debe empezar a utilizarse solamente tras una autorización separada para vender y después de que exista una orden real. Antes de pedir al proveedor, se debe confirmar el pago, la variante, el coste, el stock y el plazo actuales. No deben almacenarse nombres, teléfonos, direcciones ni información de pago del cliente: el control usa el número de orden como referencia interna.

La plantilla complementa, pero no reemplaza, el flujo de pedidos y soporte ya definido para la oferta.[1]
